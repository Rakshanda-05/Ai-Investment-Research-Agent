# 📈 AI Investment Research Agent

An AI-powered investment research platform that analyzes stocks using multiple AI agents to generate structured investment insights and Buy / Hold / Sell recommendations.

🌐 **Live Demo:** https://ai-investment-research-agent.lovable.app/

---

## ✨ Features

- 🤖 Multi-Agent AI workflow
- 📊 Fundamental analysis
- 📈 Technical analysis
- 📰 Financial news & sentiment analysis
- ⚠️ Risk assessment
- 📑 AI-generated investment reports
- 📱 Responsive modern UI

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **AI:** LLMs, Financial APIs, News APIs
- **Deployment:** Lovable

---

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/AI-Investment-Research-Agent.git

cd AI-Investment-Research-Agent

npm install

npm run dev
```
